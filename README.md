# Olga. Цветы — сайт цветочного магазина с админкой

Сайт по дизайну «Галерея» (белый фон, тёплая серая подложка, чёрный текст, тонкий красный акцент) и пожеланиям Ольги:

- **видео-обращение** на первом экране (звук по кнопке);
- **«Написать флористу»** — чат прямо на сайте, ответы Ольга пишет из админки;
- телефон и **Instagram** («посмотрите наши работы») в первом экране;
- **Букеты**: моно · авторские · с оформлением · только лента;
- **Композиции**: моно · авторские · в сумочках · в коробочках (корзин нет);
- **Конструктор вашего букета**: цветок — цена за стебель — количество, оформление «без / матовая прозрачная плёнка», кнопка «Итог»;
- корзина и оформление заказа (зоны доставки, интервалы, открытка), заказы падают в админку и (по желанию) в Telegram.

Всё — тексты, фото, видео, цены, разделы, товары, цветы конструктора, зоны доставки, телефоны, вопросы-ответы — правится в админке `/admin` без программиста.

## Технологии

- **Next.js 16** (страницы статические, пересобираются сами после сохранения в админке — поэтому очень быстро);
- **Payload CMS 3** — админка на русском (как WordPress, но встроена в сам сайт);
- **Postgres** (бесплатно: Neon через Vercel) — база данных;
- **Vercel Blob** — хранилище фото и видео; фото при загрузке автоматически ужимаются в WebP нескольких размеров;
- шрифты Noto Serif Display / Source Serif 4 / Inter Tight лежат на самом сайте (без Google Fonts), только кириллица + латиница.

## Как разместить на Vercel (бесплатно, ~10 минут)

1. Зайти на [vercel.com](https://vercel.com) через GitHub → **Add New… → Project** → выбрать репозиторий `olga-cveti` → ветку с сайтом.
2. До нажатия Deploy, в **Environment Variables** добавить:
   - `PAYLOAD_SECRET` — любая длинная случайная строка (например, 40 любых букв и цифр);
   - `ADMIN_PASSWORD` — пароль для первого входа в админку (логин `rura.alla@bk.ru`);
   - `NEXT_PUBLIC_SERVER_URL` — можно не задавать, пока нет своего домена (адрес возьмётся у Vercel). Когда подключите домен — впишите его, например `https://olga-cveti.ru`.
3. Нажать **Deploy** (первый раз может упасть — это нормально, базы ещё нет).
4. В проекте: **Storage → Create Database → Neon (Postgres)**, регион **Frankfurt** → Connect to project. Затем **Storage → Create → Blob**, регион **Frankfurt** → Connect to project. (Сервер сайта тоже во Франкфурте — `vercel.json`, ближе к России.) Vercel сам добавит `POSTGRES_URL` и `BLOB_READ_WRITE_TOKEN`.
5. **Deployments → … → Redeploy.** При сборке автоматически создадутся таблицы и стартовое наполнение (разделы, букеты, цветы, тексты).
6. Открыть `https://<адрес>/admin`, войти: `rura.alla@bk.ru` + пароль из шага 2. Пароль потом можно сменить в разделе «Администраторы».

Когда появится свой домен — **Settings → Domains** в Vercel, и поменять `NEXT_PUBLIC_SERVER_URL`.

### Необязательно

- **Уведомления в Telegram** о заказах и сообщениях чата: админка → «Контакты и настройки» → «Чат и уведомления» (токен бота от @BotFather и свой chat id).
- **«Забыли пароль?»** по почте: переменные `SMTP_HOST=smtp.mail.ru`, `SMTP_PORT=465`, `SMTP_USER=rura.alla@bk.ru`, `SMTP_PASS=<пароль приложения mail.ru>`.
- **Яндекс.Метрика**: номер счётчика в «Контакты и настройки» → «Поисковики и подвал».

## Локальная разработка

```bash
cp .env.example .env          # указать POSTGRES_URL локальной базы и ADMIN_PASSWORD
npm install
npm run migrate               # создать таблицы
npm run seed                  # стартовое наполнение (один раз)
npm run dev                   # http://localhost:3000, админка — /admin
```

Изменили поля в `src/collections` или `src/globals` → `npm run migrate:create -- <имя>` и закоммитить файл миграции: на Vercel он применится сам при сборке.

## Где что лежит

| Путь | Что |
| --- | --- |
| `src/app/(frontend)` | страницы сайта и стили (`styles.css` — дизайн-система «Галерея») |
| `src/components` | шапка, подвал, карточки; `client/` — конструктор, корзина, чат, видео |
| `src/collections` | Заказы, Чат, Товары, Разделы, Цветы для конструктора, Фото и видео, Страницы |
| `src/globals` | Главная, Конструктор, Доставка, О нас, Контакты и настройки |
| `src/app/(frontend)/shop-api` | приём заказов и сообщений чата (цены пересчитываются на сервере) |
| `src/seed` | стартовое наполнение; фото в `src/seed/images` — ориентиры из макета, заменить на съёмку Ольги |
